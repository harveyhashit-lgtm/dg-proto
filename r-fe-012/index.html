前台多语言（语言包）

R-FE-012 · 需求文档 v0.5 · 前台-通用 / 运营管理后台-内容配置 · 产品经理 Harvey · 2026-11-23

目标

前台界面文案全部抽成语言包，一种语言一份、按 key 对应。以后新增国家语言（如孟加拉语）只加一份语言包、站点开启即可，不改页面代码。本期首批：英文 + 他加禄语（补全）。

现状（正式站 77slot.com，PC / H5）

框架前端已按 key 取文案，找不到 key 回退英文
语言包在前端代码里：英文 1542 条；西班牙语 1520 条；他加禄语只有 14 条
站点语言站点配置下发默认语言、可选语言。菲站：默认英文，可选英文、他加禄语；美国站：英文
语言弹窗PC 左侧菜单底部、H5 侧边菜单「Language」；弹窗显示国家名 + 国旗（如 United States）
写死文案约 200 条没走语言包：推荐计算器、下载落地页、报错提示、Spin、改密码、网站地图、Bonus、VIP、钱包、合规页、游戏分类名等（准确清单以开发抽取为准）
金额 / 日期约 12 条文案带 $ / USD 或写死金额；部分日期固定格式
后台内容活动标题 / 说明 / 按钮文字、Banner 文字、公告 / 站内信、转盘格子名等都是单语言字段

一、前台语言包前端

文案全部进语言包页面文字、按钮、占位文字、提示、弹窗、报错、空状态、无障碍文字、游戏分类名等全部按 key 取，代码里不再写死界面文案。英文包为基准包（key 最全）
一种语言一份每种语言一个文件（如 en.json、tl-PH.json），key 与英文包一一对应；变量用占位（{amount}、{currency}、{date}），金额、币种不写死在文案里
放哪里放前端代码，随版本发布；不做总控页面。加语言 / 改词条 = 改语言包文件 + 前端发版，不改页面代码
缺 key 检查提供脚本，列出某种语言相对英文包缺哪些 key
选语言玩家手选过的 > 站点默认语言 > 英文；不按浏览器语言 / IP 自动选；刷新后保持
语言弹窗只列站点开启的语言；显示语言名（该语言自己的写法：English、Tagalog），国旗可保留
兜底当前语言缺某条 key → 显示英文那条；站点开启了前端没有语言包的语言 → 按英文显示；不显示 key 名或空白
格式金额、币种符号、千分位、小数位按站点配置；日期按当前语言格式、时区按站点
他加禄语补全全部 key（翻译用 AI 出，写进语言包文件）

v0.5 新增 配置样式原型（以亏损救援活动为例，可点击）：后台活动按语言配置文案和图片 →

涉及文字活动标题、活动说明 / 规则、活动按钮文字、Banner 标题文字、公告、站内信、转盘格子名称（完整字段清单请开发列出）
涉及图片 v0.4后台配置、前台展示的各种图片：Banner 图、活动封面 / 详情图、弹窗图、公告 / 站内信里的图、转盘等活动素材图（完整清单请开发列出）；PC、H5 分开传的图，每种语言各传一套
编辑方式这些文字和图片按站点开启的语言各填 / 各传一份（如菲站：English / Tagalog 两个输入框或页签）；后台界面本身仍是中文
必填站点默认语言那份必填 / 必传，其它语言选填
前台显示按玩家当前语言返回 / 显示；该语言没填 / 没传 → 显示站点默认语言那份（文字、图片各自回退）
存量数据上线时现有文字和图片全部作为站点默认语言（菲站 = 英文）那一份，运营不用重填 / 重传
配置样式 v0.5编辑页「文案与图片」最上面一排内容语言页签 = 站点支持语言（总控已有），默认语言排第一标「默认」，页签显示已填几项；活动的 13 个文字 / 图片字段分语言，「展示位置、宽卡排序」及「活动配置」页不分语言；非默认语言的空字段用橙色提示前台显示的默认语言内容；「复制 English 内容」只填空字段；保存时默认语言必填项没填会切回默认语言页签标红。前台逐字段取值：当前语言 → 站点默认 → English。Banner、公告、站内信、转盘等按同样方式
新开语言已有内容该语言为空，前台回退默认语言，运营按需补填 / 补传

新增一种语言的流程（上线后）

  1. 新增语言包文件（AI 翻译），用脚本检查缺失 key 并补齐
  2. 前端发版
  3. 站点配置开启该语言，需要的话设为默认语言
  4. 运营在后台给活动、公告、Banner 等补填该语言文字、补传该语言图片（不补显示默认语言）
  5. 前台语言弹窗自动出现新语言

请开发确认

  1. 写死文案的准确清单和数量，抽取改造工作量
  2. 后端返回的报错 / 提示怎么多语言：返回错误码由前端按语言显示，还是后端按请求语言返回
  3. 后台需要多语言的文本字段和图片完整清单；短信、邮件模板能否按语言分
  4. 游戏大厅接口的 lang 参数现在是否生效
  5. 活动文案和图片按语言怎么存（如按 活动 + 语言 存 13 个字段），其它后台内容是否同一套；「刷新C端缓存」是否要按语言分
  6. 前端代码里自带的、带文字的图片（如下载落地页图）有哪些，是否也按语言各放一套

不做

  • 总控语言包管理页面
  • 运营管理后台 / 总控界面本身的多语言
  • 游戏名、厂商名翻译
  • 右到左语言排版
  • 多皮肤
