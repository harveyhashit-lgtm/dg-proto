后台 Tab 统一标准

一、走查发现的问题

1. 贴边、没留白

  • 充提限制设置：Tab 在白卡片里，左右边距是 0，「每日收款额度」直接贴着卡片边框
  • 充值 / 出款通道配置等 8 页：Tab 放在灰底上，但下边距有 0、4、12、15px 四种；渠道回传记录、广告回传记录是 0，Tab 底线直接压着下面的卡片
  • 原因：10 个页面用了 7 套自写样式，每页各写各的间距

2. 切换时跳、卡

  • 下划线跟不上：充值通道配置「法币」面板内容很长（约 5000px，一次全部渲染），切回「法币」时页面卡顿，0.6 秒时下划线还停在旧位置、宽度也不对，1.5 秒后才归位
  • 切菜单位置跳：充值通道、出款通道、渠道管理、广告像素的 Tab 上面多一整行「刷新 / 新增」按钮，标签管理上面多一行空白，在菜单之间切换时 Tab 忽上忽下

二、标准

做成一套全局 Tab 样式（例如 .page-tabs、.card-tabs），删掉上面 7 个页面里的自定义类。

1. 页面级 Tab（切换整块数据，默认用这种）

示意
法币加密货币
刷新新增通道
筛选卡片 / 表格卡片 …
  • 位置：放在灰底上、第一张白卡片上面，不放进卡片；是页面的第一个元素，上面不再放别的行
  • 左右：左边与下方卡片外边对齐（margin: 0）
  • 页面按钮（刷新、新增通道等）放到 Tab 同一行最右边，不再单独占一行
  • 下边距：Tab 底线到下方第一张卡片 12px
.page-tabs { margin: 0; }
.page-tabs > .el-tabs__header { margin: 0 0 12px; }
.page-tabs .el-tabs__nav-wrap::after { height: 1px; background: var(--cc-border); }

2. 卡片内 Tab（只用在一张卡片里切内容）

示意
每日收款额度充值引导
卡片内容（左右 16px，和 Tab 文字对齐）…
  • Tab 做成卡片的头部，左右 16px，和卡片内容左边对齐；底线贯通卡片
  • Tab 底线到卡片内容 16px
.card-tabs > .el-tabs__header { margin: 0 0 16px; padding: 0 16px; }

3. 两种都一样的规则

  • Tab 高 40px，字号 14px；选中文字和下划线用主题绿 var(--cc-emerald)，下划线 2px
  • Tab 之间间距用 Element Plus 默认（第一个左边 0，其余 padding: 0 20px），不要单独改
  • 面板加 lazy：切到哪个才渲染哪个，避免切换时卡顿、下划线跟不上
  • 每个 Tab 记住自己的筛选条件和页码，切回来不清空
  • 当前 Tab 写进地址（如 ?tab=crypto），刷新后停在原来的 Tab

四、验收

  1. 上面 10 个页面，Tab 文字左边都有对齐：页面级与下方卡片外边对齐，卡片内与卡片内容对齐，没有贴边
  2. 在这 10 个菜单之间来回切，页面级 Tab 都在页面最上面，位置不跳
  3. Tab 底线到下方卡片的距离：页面级都是 12px，卡片内都是 16px
  4. 充值通道配置在「法币 / 加密货币」之间连续切换，下划线立刻对准文字，页面不卡
  5. 切到第二个 Tab 后刷新页面，还停在第二个 Tab；切回第一个，原来的筛选条件还在
