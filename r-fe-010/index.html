快捷注册 / 登录增加 Facebook

R-FE-010 · 需求文档 v1.0 · 前台-注册登录 · 产品经理 Harvey · 2026-11-21

现状

注册和登录弹窗的第三方登录只有 Telegram、Google；后台会员「注册方式」只认 email / mobile / google / telegram / guest / wallet。

改为

位置注册和登录弹窗「OR」下面加 Facebook 按钮，和 Telegram、Google 并排（三个一行）
流程和 Google 一样：点按钮 → Facebook 授权 → 新用户自动注册并登录，老用户直接登录
拿哪些信息Facebook 用户 ID、名字、头像、邮箱（有就拿）；不要求手机号
新用户和 Google 注册一样：注册奖励、邀请码、渠道归因、注册 IP / 设备限制照常生效
后台会员列表、详情的「注册方式」显示 Facebook；「第三方账号」显示 Facebook 账号
开关每个站点能单独开关 Facebook 登录，关掉时前台不显示按钮

前置条件

  • 建 Facebook 开发者 App，拿 App ID / App Secret；配置 77slot.com 为授权域名，填隐私政策地址和「数据删除」说明地址
  • 申请上线（Live）模式；拿邮箱需要 email 权限（基础权限）
  • App ID、Secret 放后端配置，不写在文档或工单里

涉及页面

  • 前台：注册弹窗、登录弹窗（PC / H5）
  • 运营管理后台：会员列表、会员详情

不做

  • 不改 Telegram、Google 登录
  • 不做 Facebook 账号绑定到已有账号

验收

#操作预期
1新 Facebook 账号点 Facebook 按钮一键注册并登录，拿到注册奖励
2同一个 Facebook 账号再点一次直接登录，不重复注册
3注册时填了邀请码上级关系正确
4后台会员详情注册方式显示 Facebook
5站点关掉 Facebook 开关前台不显示按钮
