只改两处：充值加数量输入和「≈ 到账 ₱」；提现在金额下加「≈ 到账」。约合值由新接口返回，下方参数用来模拟接口。默认填好：充值 100 USDT；提现选 USDT、输入 ₱5,000。数值可以直接改。

改什么

钱包结构不变，只加两处（PC、H5 相同）：

  • 充值（数字通道）：支持多种数字币（按通道配置，现网为 USDC / USDT / BNB / ETH / SOL / TRX），每个币种都在「Select network」下方加数量输入框和快捷金额，下面显示「≈ 到账 ₱」。
  • 提现（数字币只保留 USDT，USDC / TRX 下架；币种按钮只显示 USDT，不再下拉）：金额改为按 ₱ 输入（前缀 ₱），金额输入框下方显示「≈ 到账 X 币」和汇率。网络、钱包地址等其他部分与现网一致；选 PHP 时法币提现不改。

约合值全部由新增的估算接口返回，前台不做计算。其余内容与现网一致。

交互规则

场景规则
充值数量输入单位为所选币；USDT / USDC 最多 2 位小数，其他币最多 8 位。快捷金额、最低、最高取现有通道数据。切换币种或网络时清空。只做预估，不生成订单。
提现金额（数字币）按 ₱ 输入，最多 2 位小数，前缀 ₱。接口限额按币计算（如 USDT 20.00–50,000.00），前台按汇率折成 ₱ 来校验，超出时提示「Minimum withdrawal USDT 20.00 (≈ ₱ 1,273.80)」。Max 取可提现余额和最高限额折成 ₱ 后的较小值。提交时传 ₱ 金额，由后端换算成币。
调用估算接口输入合法后停顿 300ms 再请求；新请求返回前，旧请求的结果直接丢弃。提现切换网络时，保留金额并重新估算。
显示充值：≈ ₱ 6,369.00 + 小字 1 USDT ≈ ₱ 63.69；提现：≈ 78.50 USDT + 小字 1 USDT ≈ ₱ 63.69。下方固定一行预估说明。
不显示约合行输入为空或为 0、超出最低 / 最高 / 余额（沿用现有红字提示）、接口失败或超时。都不报错，不影响充值地址和提现提交。

估算接口（新增）

字段说明
入参通道编码、方向（充值 / 提现）、金额充值金额按币，提现金额按站点法币（₱）
出参约合金额、单位、汇率、汇率时间后端已有的手续费、优惠直接算进约合金额，前台不单独展示；汇率取 2 位，约合金额按这个汇率计算并向下取 2 位，保证和汇率小字一致

不做

PHP 充值、提现不改；提现其他数字币（USDC / TRX 等）本期不开放；不单独展示手续费、优惠；不锁定汇率；钱包其他内容不改。
