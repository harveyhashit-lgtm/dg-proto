先在「后台」改配置并保存，再切到「前台」看效果。前台只演示 Invitation、Direct Referral Data、Referral Bonus 三个 Tab，其它 Tab 不变。示例有 6 个直属下级，累计充值 / 投注是固定值，用来看不同配置下的判定结果。演示默认「参与品牌」为指定、只勾电子游戏整行，所以 10482931 投注 ₱3,450 里只有 ₱600 是电子游戏，仍是 Pending；改回「全部」保存后立即达标。品牌取测试前台 Providers 页的 6 个，各品牌所属类型是示例。

改什么

邀请人每有一个直属下级的累计充值和累计有效投注都达到后台门槛，就得到一笔固定金额的邀请奖励。每个下级永久只算一次，有一个算一个。

  • 后台：代理中心新增独立页面「邀请奖励配置」；代理佣金记录、代理列表各加一点展示。
  • 前台：Refer & Earn 的 Invitation 金额改为取配置，Direct Referral Data 加 Status 列，新增 Referral Bonus Tab。
  • 邀请链接、邀请码沿用现有，不改。
现状：后台没有这项配置的界面，前台 Invitation 却一直显示「Earn ₱1,499.73 per referral」，玩家看得到但实际不发。本期一起修掉。

发放流程

下级充值到账 / 注单结算或后台开启启用、启用中保存配置时，对所有未发奖下级补判一次→启用中？→这个下级发过奖励？→命中同 IP / 同设备排除？→累计充值、累计投注都达标？投注只算参与品牌范围内的游戏
未启用→不判定
已发过→不再发（永久一次）
命中排除→不发，前台显示 Not eligible
未达标→不发，前台显示 Pending + 进度
达标→给直属上级发一笔邀请奖励（未领取），计入 Available Amount→玩家 Claim→入账 + 加流水

判定规则

项规则
谁是下级沿用现有绑定：通过邀请链接或邀请码注册的直属下级。只发直属上级，不往上分层
累计充值下级注册以来所有到账充值订单（法币 + 链上）合计。后台人工加款、活动奖励、佣金都不算
累计有效投注下级注册以来已结算注单的有效投注合计，口径同现有投注佣金。参与品牌为「指定」时，只算所选品牌、所选类型的注单
改参与品牌未发过奖励的下级按新范围重新统计累计有效投注（含改之前的历史注单）；已发放的不变、不收回
有效下级累计充值和累计有效投注同时达到门槛（门槛为 0 的那项视为已满足）
每个下级几次永久一次。发过之后这个下级再充值、投注都不再发
老下级上线前已注册的下级也算，和注册时间无关
判定时机启用状态下，下级每笔充值到账、每笔注单结算后判定一次
开启启用首次开启或关闭后再开时，对所有还没发过奖励的下级判定一次，已达标的立即发
保存配置启用状态下保存（改门槛、参与品牌、排除项等）后，同样对所有还没发过奖励的下级判定一次，按新配置已达标的立即发
关闭启用不再产生新奖励；已生成未领取的照常可领
同 IP / 同设备勾选后，下级注册时的 IP / 设备号与邀请人注册时相同，该下级永远不算有效下级。只影响之后的判定，已发放的不收回
金额按达标那一刻的配置金额发；之后改金额不影响已发的
发放与领取生成一笔「固定邀请奖」（沿用已有佣金类型）给邀请人，状态未领取，计入 Available Amount，走现有 Claim；不设领取期限
领取流水打码量 = 奖励金额 × 领取流水倍数，基数固定为奖励金额。每笔奖励保存发放时的倍数，之后改倍数不影响已发的。一次 Claim 同时包含邀请奖励和其它佣金时，各笔按自己的倍数分别算再相加
与免费转盘免费转盘活动里的有效邀请条件单独配置，不受本页影响

上线前

开发测试重点

  • 一个下级只发一次：充值回调和注单结算可能并发，判定和发放要以「邀请人 + 下级」唯一防重。
  • 累计口径：充值只算到账订单，人工加款、活动奖励、佣金都不算；投注只算已结算有效投注。
  • 开启启用时的补判：要覆盖所有未发过奖励的下级，包括上线前注册的老下级和关闭期间达标的下级。
  • 同 IP / 同设备：比对的是双方注册时的 IP / 设备号，不是最近登录。
  • 快照：奖励记录保存发放时的金额、门槛和领取流水倍数，后台改配置不影响已发记录。
  • 参与品牌按「品牌 + 类型」过滤：存的是 品牌码@类型 时只算该品牌在该类型下的注单，同品牌其它类型不算；改范围后未发奖的下级要按新范围重算历史注单，不能只从改的那一刻开始累加。
  • 两个投注数不是一回事：Direct Referral Data 原有的 Bet Amount 是全部游戏、按日期筛选；Status 进度里的 Bet 是参与品牌范围、注册以来累计，两者不同属正常。
  • 混合 Claim 的流水：邀请奖励和其它佣金混在一起领，流水按每笔自己的倍数分别算，不能整笔套一个倍数。
